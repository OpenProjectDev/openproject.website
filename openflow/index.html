OpenFlow

AI agents that pick up where they left off

OpenFlow is one guide that a Claude Code agent follows in your repository. The agent keeps the project’s state, decisions and history in plain files under git, and you stay the one who decides

01How a session starts

Every session starts in the right place

No new session has to read old conversations. Each one reads three things, then says where things stand

  1. 1MASTER.md

    The rules: the guide’s, word for word, and the project’s own on top

  2. 2system/STATE.md

    Where the work stands right now

  3. 3system/comms/

    Messages waiting for it

  4. 4One line

    Where things stand and what’s next, said before it acts

02What it gives you

Order, kept in plain files

One place for each kind of fact

What’s happening now, what’s next, stable facts, decisions and history each have their own file, so they can’t drift apart

Facts you can trust

Something is written as fact only once it was seen in a file or a command’s output, or you said it

You decide

The agent asks about facts only you know, makes small calls itself and says so, and leaves anything that can’t be undone for you to order

Subagents with limits

Each gets a written brief, a report folder and a cap on how many run at once, and its report is checked

Secrets kept out

Secrets and client material stay out of git, and documents with legal value are never deleted

Agents that talk

Projects on one machine message each other through folders in each other’s repositories

03Set it up

Three steps

  1. 1

    Copy guide/BOOTSTRAP.md into the root of your repository

  2. 2

    Open Claude Code there and ask it to set the repository up with BOOTSTRAP.md

  3. 3

    Answer its three questions: the project’s name, whether it may touch live systems, and whether it may go public one day
